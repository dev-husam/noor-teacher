# نور · المعلّم الإسلامي الذكي

تطبيق ويب عربي أولًا (RTL) لإدارة صفوف التربية الإسلامية وحلقات القرآن للأطفال.

## التشغيل

```bash
npm install
npm run dev      # http://localhost:5180
npm run build    # نسخة الإنتاج في dist/
```

## الأقسام

| القسم | المزايا |
|---|---|
| 🏠 الرئيسية | ترحيب بالتاريخ الهجري، إحصاءات اليوم، آية وحديث اليوم، نجم اليوم، نقاط الأسبوع، آخر النشاطات |
| 👦 الطلاب | منح النقاط بلمسة، تحديد متعدد، الصف كاملًا، تراجع، ملف كامل لكل طالب، إضافة قائمة أسماء، تقرير لولي الأمر (واتساب/طباعة) |
| 📅 الحضور | حاضر/متأخر/غائب/بعذر، «الكل حاضر»، أيام سابقة، سجل ١٤ يومًا بالنسب |
| 🧰 أدوات الصف | عجلة اختيار عشوائي، مؤقت بملء الشاشة، جرس الانتباه، إشارات الصف، مقياس الهدوء بالميكروفون، تكوين المجموعات والفرق |
| 📖 القرآن | جلسة تسميع مع اقتراح السورة التالية، لوحة حفظ تفاعلية، تقدّم كل سورة (الفاتحة + جزء عمّ) |
| 🎮 الألعاب | مسابقة (طالب/فرق/الصف)، لعبة الذاكرة، رتّب الخطوات (الوضوء، الأركان، الصلوات) |
| 🌙 تعلّم | بطاقات أدعية تنقلب، أسماء الله الحسنى، آيات وأحاديث — مع عرض كبير للشاشة |
| 🎁 المكافآت | متجر استبدال النقاط، أوسمة تلقائية، مستويات النمو 🌱→🌕 |
| 🏆 لوحة الشرف | منصة تتويج، ترتيب اليوم/الأسبوع/الكل، سباق الهجن للفرق |
| 📈 التقارير | إحصاءات، أكثر السلوكيات، من يحتاج اهتمامًا، تصدير Excel، طباعة |
| ⚙️ الإعدادات | عدة صفوف، تعديل السلوكيات والمكافآت، الوضع الليلي، العربية/English، نسخ احتياطي واستعادة |

البيانات محفوظة محليًا في المتصفح (localStorage). الهوية البصرية موثّقة في `brand/brand-guide.html`.
